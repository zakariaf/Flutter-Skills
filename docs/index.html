Install

Add the skills to any project

Pick the path that fits your agent. The universal installer works everywhere; native integrations are one command each.

# Installs into 70+ agents (Cursor, Codex, Copilot, Cline, …)
$ npx skills add zakariaf/Flutter-Claude-Code-Skills            # all skills
$ npx skills add zakariaf/Flutter-Claude-Code-Skills --list     # browse first
$ npx skills add zakariaf/Flutter-Claude-Code-Skills --skill flutter-architecture
# This repo is a Claude Code plugin marketplace
/plugin marketplace add zakariaf/Flutter-Claude-Code-Skills
/plugin install flutter@flutter-skills

# Skills then appear as e.g. /flutter:flutter-architecture
# Copy the skills into a single project (committed for the whole team)
$ git clone https://github.com/zakariaf/Flutter-Claude-Code-Skills
$ mkdir -p .claude/skills
$ cp -R Flutter-Claude-Code-Skills/skills/* .claude/skills/
# Make every skill available in every project on your machine
$ for d in /path/to/Flutter-Claude-Code-Skills/skills/*/; do
    ln -s "$d" "$HOME/.claude/skills/$(basename "$d")"
  done

Why it works

Opinionated, correct, and out of your way

🎯

Auto-loading

A rich description is the trigger — the agent loads a skill only when the task matches, so context stays lean.

📚

Progressive disclosure

A lean SKILL.md points to references/, examples/ & scripts/ that load on demand.

🧭

One canonical stack

Riverpod 3.x, go_router, Drift, Material 3 — reconciled to a single vocabulary so 33 skills never contradict each other.

🎨

Structure, not aesthetics

Teaches how components, themes & layouts are structured — never “the colour must be #…”. Drop them into any design.

🔌

Cross-agent

Built on the Agent Skills open standard — the same files work in Claude Code, Cursor, Codex, Copilot and 70+ more.

✅

Adversarially reviewed

Every skill was reviewed for API correctness (Riverpod 3.x, Drift, WCAG) and scrubbed of app-domain & design-token specifics.
